# TikTok Intelligence Skill

Evidence-first TikTok song identification for AI agents.

## What it does

- Accepts a public TikTok HTTPS link.
- Retrieves accessible public media without cookies, login bypass or access-control circumvention.
- Enforces a maximum 10 MiB media file and 90-second processing segment.
- Extracts up to three 12-second audio samples from each segment and queries AudD for song matches.
- Returns artist, title, album metadata, provider links, and the approximate timestamp of each sampled match.
- Returns a signed continuation cursor when more of the video is accessible. The caller continues only when requested.
- Keeps the worker API key on the server; the Vercel app proxies requests to the worker.
- Leaves broader video interpretation to the connected AI agent.

Song recognition is probabilistic, not guaranteed. Short clips, voice-over, crowd noise, sped-up audio, remixes, and unavailable catalogue tracks can produce no match or an incorrect candidate. The service reports provider candidates and evidence rather than inventing certainty.

## Deploy

### 1. Deploy the worker to Render

Use the root `render.yaml` Blueprint. Configure:
- `WORKER_API_KEY` — generated by Render.
- `CURSOR_SECRET` — generated by Render.
- `AUDD_API_TOKEN` — create an AudD account and add its API token.
- `MAX_MEDIA_BYTES=10485760`.
- `MAX_SEGMENT_SECONDS=90`.

The worker exposes authenticated asynchronous endpoints:
- `POST /v1/song-jobs` with `{ "url": "https://www.tiktok.com/@creator/video/..." }` to start.
- `GET /v1/song-jobs/{job_id}` to poll.
- Send `{ "cursor": "..." }` to start the next segment when the user requests continuation.
- `GET /health` for health.

### 2. Deploy the Next.js app to Vercel

Set these server-side environment variables:
- `WORKER_URL` — your Render worker base URL, without a trailing slash.
- `WORKER_API_KEY` — the same key configured on Render.
- `GROQ_API_KEY` — optional metadata-only context note.
- `GROQ_MODEL` — optional; defaults to `llama-3.3-70b-versatile`.

Do not prefix worker secrets with `NEXT_PUBLIC_`.

### 3. Local development

Requires Node.js 20.9+.

```bash
npm install
npm run dev
```

## Limits and operational notes

- One recognition job processes one segment of at most 90 seconds.
- Downloaded media is capped at 10 MiB. Oversized media is discarded.
- AudD's standard recognition endpoint analyses short samples (up to about 12 seconds per request); this worker samples at 0, 30 and 60 seconds within each segment. Each sample is a separate provider request.
- AudD credentials and current plan limits apply. New-account trial availability and paid pricing can change.
- Job state is held in worker memory. A worker restart loses in-flight jobs; clients must start again.
- Render free instances can sleep and have constrained resources. Do not treat free-tier availability or processing latency as guaranteed.
- TikTok may block public media retrieval. When it does, the API reports an unavailable error; it does not bypass restrictions.

See [worker/README.md](worker/README.md) for the worker API details.
